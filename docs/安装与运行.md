# 下载即用（Windows 免安装包）

> 不想装 Python、Node、数据库，只想在答辩机或自己电脑上把系统跑起来，看这一页。

## 一、下载

打开 [Releases](https://github.com/sit-rhg/culturalwalk-platform/releases)，
下载最新一个 **`CulturalWalk-<版本>-windows-x64.zip`**（约 30–60 MB，视 Python 运行时大小）。

## 二、解压 + 启动

1. 解压到任意目录（路径里有中文、空格都可以）。
2. 双击 `start.bat`。
3. 第一次启动会自动建库、灌演示数据（约 10 秒），然后自动打开
   <http://127.0.0.1:8000>。

关掉黑窗口即停止服务。数据都在包内的 `data\` 目录：

- `data\demo.db` —— SQLite 数据库，删掉就是全新环境，下次启动重新灌种子
- `data\media\` —— 上传文件的本地存储

## 四、包里是什么

```
start.bat            启动入口（建库 → 种子 → 起服务 → 开浏览器）
runtime\             Python 3.12（CI 打包时塞进去的，用户机器不用装）
site-packages\       运行依赖
app\                 后端源码（FastAPI）
migrations\          Alembic 迁移
web\                 构建好的前端（由后端直接托管，不需要 vite）
scripts\seed_demo.py 演示数据
data\                运行期数据（首次启动时创建）
```

## 五、常见问题

- **杀毒软件拦 start.bat / python.exe**：免安装包里的 python 是官方 CPython，
  被拦时加白名单即可；也可以只下载源码按 README 用 venv 跑。
- **端口 8000 被占**：先关掉占用进程，或修改 `start.bat` 最后一行的 `--port`。
- **自己的机器上想改成 PostgreSQL**：设环境变量 `DATABASE_URL`，先
  `python -m alembic upgrade head` 再启动即可（迁移脚本随包提供）。
- **没有 python.exe 的情况**：包若不带 `runtime\`（来源是手动打的小包），
  `start.bat` 会退回 `py -3.12` / `python`；缺依赖时按提示
  `python -m pip install -r requirements.txt`。
